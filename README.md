# FruityClaw-Studio

An open-source, native, local, cross-platform digital audio workstation modelled on FL Studio,
with agentic AI integration built in rather than bolted on. The Studio is a fully functional DAW
with no AI configured; the Assistant is a layer on top of a complete product.

See `docs/CORE_DOCUMENT.md` for what the project is and what has been decided.
